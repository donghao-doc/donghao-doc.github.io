# 小程序基础

## 注册账号与添加成员

[微信公众平台](https://mp.weixin.qq.com/) 注册小程序账号，按注册流程进行。

小程序上线前，还要完成**小程序备案**和**微信认证**。

添加项目成员和体验成员，要输入对方的微信号（不是手机号）。

## AppID 与 AppSecret

| 名称          | 是什么        | 主要用途           |
|-------------|------------|----------------|
| `AppID`     | 小程序的唯一身份凭证 | 新建项目、上传代码等     |
| `AppSecret` | 小程序密钥      | 服务端调用需要密钥的 API |

:::danger
`AppSecret` 应由后端保管，不要放在前端或提交到代码仓库。
:::

## 全局文件

全局文件作用于整个小程序，影响小程序的每个页面，**必须放到项目的根目录下**。

| 文件         | 说明                       |
|------------|--------------------------|
| `app.js`   | **入口文件**，可存放全局逻辑、全局共享数据  |
| `app.json` | **全局配置文件**，如配置页面路径、窗口表现等 |
| `app.wxss` | **全局样式文件**，可存放公共基础样式     |

## 调试基础库

**微信基础库**是小程序的运行环境，提供了小程序运行所需的框架、组件、API 等。

:::warning
使用组件或 API 时，注意检查当前基础库版本是否支持。
:::
